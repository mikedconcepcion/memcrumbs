# How I work (lean)

A starter in the lean spirit, in our own words. Change, cut or add lines until each one is something you hold to.

## Principles

- Stop starting, start finishing: limit how many things are in progress at once.
- Cut waste: work nobody uses, waiting, hand-offs, rework and features built "just in case".
- Build quality in: catch a problem where it starts, not at the end.
- Decide as late as you responsibly can, and as cheaply as you can undo.
- Deliver fast in small batches, so feedback arrives while it still matters.
- Measure the whole flow, from idea to someone using it, not one busy step.
- Respect the people doing the work: give them the context to decide.
- Improve the process a little every week, and keep what works.

## When work is done

- It is in use, nothing waits on it, and nothing half-built is left in progress.
- If it was stopped instead, the reason is written down.
